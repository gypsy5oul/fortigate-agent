2. 3. Gate table: fill the lab column of runbook 5.5, have a second person sign.
4. Flip: change `INVESTIGATOR_MODE=shadow` to `adk` in `.env`, then `docker compose up -d app` (`docker compose restart` does not re-read `.env`). Expect `Investigator mode: adk` in the log and HTTP 200 `ready` on `/health/ready`.
5. Watch the first hour with the table of runbook 5.7: `docker compose exec -T app python scripts/shadow_report.py --mode live --since <flip time>`, the `forti_agent_*` metrics, `forti_model_consecutive_failures`, `forti_jobs_oldest_pending_seconds`, the INVESTIGATION_UPDATE cards, and the dashboard row "ADK Live Mode".
6. Roll back on any trigger: `INVESTIGATOR_MODE=legacy` in `.env` and `docker compose up -d app`. The run in flight is abandoned and its job completed by the legacy call after the 90 s lease; ADK revisions and the audit tables stay.
7. After the soak the ticket names: `git apply --check docs/reports/gate-c3-legacy-removal.patch && git apply docs/reports/gate-c3-legacy-removal.patch`, run the suite, commit, `docker compose up -d --build app`. From then on rollback is `git revert` and a rebuild.
